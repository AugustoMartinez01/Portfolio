# Portafolio — Augusto Martinez

Mi portafolio personal, con los proyectos en los que trabajé y en los que estoy trabajando.

**Ver en línea:** [tukodes.vercel.app](https://tukodes.vercel.app)

## Qué muestra

- Los proyectos, con su estado (en línea o en desarrollo). Los que están publicados llevan directo a la página.
- Una sección sobre mí y las herramientas con las que trabajo.
- Contacto por mail.

## Tecnologías

React, Vite, JavaScript y CSS. Publicado en Vercel.

## Correrlo en tu compu

El proyecto está dentro de la carpeta `portafolio`:

```bash
cd portafolio
npm install
npm run dev
```
